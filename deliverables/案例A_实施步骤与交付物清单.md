# 案例A：中小企业数字员工端到端交付 Demo —— 实施步骤与交付物清单

> 定位：为作品集补齐「数字员工品类」的完整交付实证（个人自演示 Demo），形成「业务型交付（客户）+ 工程型部署（自研）+ 数字员工交付（个人实现）」三足鼎立。
> ⚠️ **定位声明：本案例为个人自演示 Demo，客户画像为虚构典型客户，非真实客户交付。对外材料（含 D10 复盘报告、D11 演示素材包、作品集入口）必须注明此定位，避免被误读为真实项目经历。**
> 场景选定：**外贸询盘处理数字员工**（与模块03外贸跟单素材连贯，可复用已有 RPA/流程认知）。
> 目标岗位证据：FDE 前线部署工程师（进客户门→诊断业务→端到端交付→现场培训→数据量化）。

## 一、案例定义

| 项 | 内容 |
|----|------|
| 案例名称 | 外贸询盘处理数字员工端到端交付（个人自演示 Demo） |
| 目标客户画像 | 广州中小外贸企业（10-50人，无专职IT，使用企业微信办公；运维责任由交付方承担或主推云端托管） |
| 数字员工职责 | 询盘识别分类 → 产品知识问答 → 初步报价（金额需校验，超阈值转人工）→ 跟单提醒 → 异常转人工 |
| 交付形态 | 企微机器人 + 知识库 RAG + 人工确认节点 + 运营看板（主推云端 SaaS，私有化可选） |
| 成功指标 | 自动化处理率 ≥ 40%（AI 闭环完成数÷总询盘数，不含需人工确认）；人工转接率 ≤ 60%（含需人工确认与异常转人工，与自动化率互补）；平均响应时间（端到端口径）下降 ≥ 50%；月节省工时 ≥ 25 工时/月；误报价率 ≤ 5%（安全侧指标，与报价金额正确率互补）。**以上成效均为演示测算模型口径，基线为假设值，与真实客户成效分离标注** |
| 合规要求 | 跨境数据传输合规（个保法/PIPL 出境评估）、境外买家个人信息脱敏口径、云端 RAG 数据驻留说明、商业秘密访问分级（详见 Phase 2） |

## 二、实施步骤（Phase 0 - 5）

> 各 Phase 合计 **12–20 个工作日**（约 2.5–4 周，**不含缓冲**）；叠加审计与缓冲后整体按 **4–5 周**排期。
> **变更管理规则：Phase 1 起，报价规则（含价格数据）/ 需求 / Prompt 体系 / 流程节点的任何变更，均须先回归 D12 样本集且通过后方可推进。**

### Phase 0：项目启动与场景诊断（1-2 天）
- **目标**：走 FDE「进客户门 → 诊断业务 → 定义交付范围」标准动作
- **动作**：
  1. 编写《客户发现简报 Discovery Brief》（以一家**虚构但贴近真实**的典型外贸企业为背景：产品线、询盘渠道、团队分工、现有痛点）
  2. 梳理询盘处理全流程：接收 → 意图识别 → 产品匹配 → 报价 → 跟单 → 报关检查 → 客户回访
  3. 圈定数字员工边界：可自动化环节 / 必须人工环节 / 需人工确认环节
  4. 定义成功指标与数据采集口径
  5. 采集现状基线：人工响应时间、日询盘量、重复问题占比（**基线为假设值，仅支撑演示测算模型，不得写成真实客户实测数据；与真实成效两栏分离**）
- **产出**：Discovery Brief 完整版（**D1**）+ 询盘全流程与自动化边界图（**D2**）
- **验收**：新客户可套用该模板，10 分钟能讲清场景与边界

### Phase 1：数字员工搭建（低代码平台）（3-5 天）
- **目标**：在 Dify 搭建可演示的数字员工工作流（技术路线本阶段锁定）
- **动作**：
  1. **锁定主平台：Dify**（Coze 仅作对比备选，不并行推进）；同步说明 **enterprise-agent** 来源与用途：自研离线改造版，基于开源框架二次开发（上游项目与版本在 D7 部署手册中锁定并注明），用于无网/低配环境演示，属 Phase 3 备选形态，**Phase 1 即锁定，不再「二选一」悬而不决**
  2. 搭建知识库：清洗产品手册、报价规则（含价格数据）、常见问题（中文切分适配）；明确报价规则与汇率更新机制；**商业秘密分级**：知识库访问分级、报价规则防泄露（价格数据仅授权角色可见）、员工/客户可见范围
  3. Prompt 体系：系统提示词 + 输出格式校验（JSON Schema）+ 防幻觉约束（无答案时转人工） + **报价金额校验（金额/折扣超阈值强制转人工、无价格资料转人工）**
  4. 双层流设计：AI 先做 + 人只审（对齐模块02经验）
  5. 自造 **52 条**测试询盘样本集（覆盖三难度：直接可答 / 需人工确认 / 拒答），用于验收与回归；**统计效力注记：20 条样本下 90% 准确率的 95% CI 下界约 68%（Clopper-Pearson 精确法，比 Wilson 的 72.9% 更保守）；52 条样本下 90% 观测值的 95% CI 下界约 78%（Wilson 法），对外仍只能宣称区间下界；R-1 实测 96%（48/50）对应 CI 下界约 86.7%，对外按实测值重算；若要宣称准确率 ≥90%，须扩大样本量或提高实测值**
  6. 运行成本控制：估算单次对话 token 成本、设定月成本上限与降级阈值
  7. **报价规则版本控制**：报价规则（含价格数据）变更走版本管理，并触发 D12 回归（见变更管理规则）
- **产出**：工作流设计图（**D3**）+ Prompt 体系文档（**D4**，含报价金额校验与阈值转人工规则）+ 知识库构建包（**D5**，含访问分级与防泄露规则）+ 测试询盘样本集与验收/回归报告（**D12**）
- **验收**：52 条测试询盘（可分批复测），意图识别准确率 ≥ 90%（对外口径按统计效力注记执行），报价输出格式 100% 合法，**报价金额正确率 ≥ 95%（±5% 容差内，分母为实际发出报价单，未发出单计入异常转人工），金额/折扣超阈值 100% 转人工，拒答类 100% 转人工不编造，无关单静默归档且不计入闭环分子，自动化率/转接率按样本集实测（不低于/不高于 D3 §7.2 推演）**

### Phase 2：渠道接入（IM 机器人）（2-3 天）
- **目标**：打通「最后一公里」，数字员工进入企业微信/钉钉
- **动作**：
  1. 创建企微自建应用/机器人（或钉钉机器人），配置回调与消息收发
  2. 群聊 @ 提问响应、私聊问答、关键词触发
  3. 权限与安全：仅企业内部成员可用、敏感字段脱敏、操作日志；**跨境合规：境外买家个人信息脱敏口径、跨境数据传输合规（个保法/PIPL 出境评估）、云端 RAG 数据驻留说明；内容权限分级（报价规则仅限授权角色）**
- **产出**：IM 接入配置文档（**D6**，含跨境合规与数据驻留说明）+ 真实聊天记录截图 + 权限/安全说明
- **验收**：群内 @ 数字员工 3 秒内响应（**消息回执口径，不含大模型推理时间；与 Phase 4 看板的端到端平均响应时间口径分离，不得互证**），消息闭环完整；**变更须回归 D12 样本集（触发范围见变更管理规则）**

### Phase 3：现场部署（干净环境复现）（3-5 天）
- **目标**：证明主推形态（云端 SaaS）开通即用、不依赖开发者本人电脑；备选私有化形态在客户现场可复现
- **动作**：
  1. 部署形态确定：**主推云端 SaaS 版（免运维，客户无专职IT亦可运行）**；私有化（Dify Docker Compose）作为客户有合规/数据驻留诉求时的可选形态，此时**运维责任归属须明确**（谁升级/谁备份/谁值班，交付方远程运维或客户兼职IT，见 Phase 4 交接）；enterprise-agent 为自研离线改造版（Phase 1 已定义），仅作无网/低配环境演示备选
  2. 云端形态：完成租户开通与机器人配置；私有化备选形态：在全新虚拟机/旧电脑（模拟客户环境）执行一键部署脚本
  3. 验证低配环境：资源占用记录、无网/限网降级方案、本地模型或云端 API 切换
  4. 编写部署手册 + 故障排查表（启动失败/模型不可用/超时三大类）
  5. 验收口径预埋：部署启动脚本内置冒烟测试（health check + 关键接口自检）
  6. 回滚与数据保留：镜像版本化、容器数据卷挂载、失败时一键回滚到上一版本；**知识库与业务数据定期备份（每日增量 + 每周全量）+ 恢复演练**
- **产出**：部署手册（**D7**，按主推形态编写，私有化/enterprise-agent 为备选章节；含备份恢复与运维责任）+ 一键脚本 + 干净环境部署录屏 + 故障排查表
- **验收**：验收（**双轨口径**）：云端形态验证「租户开通+配置 → 冒烟测试通过」≤ 60 分钟（实施环节口径，与现场演示 60 分钟分离）；私有化备选形态验证「一键脚本启动 → 冒烟测试通过」≤ 30 分钟（备选形态验收项）；重试/熔断/降级验证通过

### Phase 4：培训与运营数据闭环（2-3 天）
- **目标**：复刻模块10培训SOP能力，形成运营数据看板
- **动作**：
  1. 制作操作手册（非技术客户视角）+ 培训视频脚本 + FAQ
  2. 设计反馈闭环：「AI 不好用」处理流程 + 迭代优化机制
  3. 搭建运营看板：使用量 / 自动化处理率 / 人工转接率 / 平均响应时间 / 月节省工时 / **误报价率 / 误答率**
  4. 指标口径定义（逐一明确计算规则与数据来源，保证可回算）：
     - 自动化处理率 = AI 闭环完成数 ÷ 总询盘数（不含需人工确认）
     - 人工转接率 =（需人工确认 + 必须人工 + 异常转人工）÷ 总询盘数，与自动化率互补（40% + 60% = 100%；**异常转人工指进入自动化流程后失败的询盘，不计入 AI 闭环完成数**）
     - 平均响应时间 = 端到端（用户发送 → 收到最终答复），**与回执时延口径分离，不得互证**
     - 月节省工时 = 人工单询盘处理耗时差 × 自动化处理量（测算模型口径）
     - 误报价率 = 报价金额超出 ±5% 容差的单数 ÷ **实际发出报价单总数**（未发出单计入异常转人工、不进入分母；与报价金额正确率 ≥95% 互补，口径对齐 D4 §4.5）
     - 误答率 = 抽查中错误答复数 ÷ 抽查数（安全侧指标）
  5. **客户交接与运维责任定义**：运维责任人（升级/备份/值班）、故障响应 SLA、退出机制（数据导出与删除）
- **产出**：培训包全套（**D8**，含运维交接与 SLA 说明）+ 运营数据看板（**D9**，模板+示例数据）
- **验收**：看板数据可回算、口径一致，能讲出「上线后怎么监控」；**变更须回归 D12 样本集（触发范围见变更管理规则）**

### Phase 5：收尾与作品集呈现（1-2 天）
- **目标**：把案例做成面试可演示、可量化的作品
- **动作**：
  1. 录制端到端演示视频（进客户门 → 搭建 → 部署 → 对话演示 → 看板）
  2. 截图归档：工作流设计、知识库、机器人对话、部署日志、看板
  3. 撰写案例复盘：痛点 → 方案 → 交付 → 成效 → 可复用资产 → 教训（**成效部分按「演示测算模型」标注，不得写成实测**）
  4. 更新作品集：新增案例入口 + 现场演示清单 + **诚信说明（独立落盘，见 D13，注明个人自演示 Demo 定位）**
- **产出**：案例复盘报告（**D10**）+ 演示视频/截图包（**D11**）+ 作品集更新与诚信说明（**D13**）
- **验收**：面试官 5 分钟内能理解全链路（**口径：口头讲解 5 分钟，不含现场演示**），现场可演示
