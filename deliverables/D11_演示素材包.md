## 一、素材包总览

素材包 = **录屏（3 档） + 关键节点截图（7 组） + 水印规范**，服务于：

1. 作品集案例入口（D13 1.2 Demo 演示入口）
2. 面试现场演示脚本（D13 2.1/2.2/2.3 三档）
3. 复盘报告与对外材料的引用素材（对齐 D10 成效口径）

> **成效数字红线**：素材中出现的所有成效数字均为**演示测算模型口径**（基线为假设值），并以 D10 终稿为准；录制解说词不得出现未标注口径的数字表述。

## 二、录制计划

### 2.1 三档版本场景脚本要点（对齐 D13 第二章）

| 版本 | 时长 | 场景脚本要点 | 素材组成 |
|------|------|--------------|----------|
| **电梯版** | 3min | 定位（30s）→ 场景痛点（30s）→ 对话演示 1–2 条（60s）→ 成效（45s，标注测算模型口径）→ 诚信声明（15s） | 1 条精简录屏 + 3–5 张关键截图 |
| **完整版** | 10min | 定位与边界（1.5min，D2 三色边界）→ 诊断输入（1.5min，D1）→ 搭建链路（1.5min，D3/D4/D5）→ 对话演示 3–5 条（2min）→ 部署与接入（1.5min，D6 + 云端 SaaS 主推）→ 看板与成效（1.5min，D9 口径可回算）→ 诚信声明（0.5min） | 分段录屏拼接（4–6 段）+ 关键截图 |
| **验收版** | 60min | 诊断（10min，D1/D2）→ 对话演示（15min，D12 样本现场抽测）→ 部署演示（20min，云端开通+配置+冒烟测试，对齐 Phase 3 双轨口径）→ 看板（10min，D9 回算演练）→ 答疑与诚信（5min） | 全流程单次录屏（可分 2–3 段） |

### 2.2 录制顺序（推荐）

1. **搭建/配置期同步截图**：Dify 工作流搭建、企微应用配置、知识库上传时顺手截屏（N0/N23 等静态节点）
2. **验收版全流程录屏**：一次完整跑通「诊断 → 对话演示 → 部署演示 → 看板」，作为母带；**母带存于非对外目录并加访问控制（受限共享/加密），对外只发布已加水印版本（§5.3）**
3. **完整版**：从验收版母带裁剪拼接，不足片段针对性补录
4. **电梯版**：从完整版精简剪辑，口播不足时单独补录定位/成效两句
5. **统一加水印 → 对照素材清单复核 → 归档**（缺水印素材不得进入作品集）

### 2.3 通用录制规范

- 分辨率 ≥ 1080p，帧率 ≥ 30fps，录屏含鼠标轨迹与键盘输入提示
- 演示环境使用 D6 企微测试群，群名含「测试/Demo」标识，避免误入真实群
- 对话演示使用 D12 样本集已标注用例（三难度各覆盖），不临时口播编造询盘；**采样分布按 D3 §7.2 比例抽取（auto 20 / 转人工 28 / 归档 2），解说词注明「本次为样本抽样，非全量分布」，避免按困难档反推自动化率**
- 涉及报价数字的演示统一使用 D5 示例价格数据，标注「示例数据」
- 录屏文件命名：`D11_<版本>_<序号>_<内容>.mp4`；截图命名：`D11_N<节点>_<内容>.png`

## 三、关键节点截图清单（对齐 D3 节点）

> 节点定义与解说口径引自 D3 §2/§3；每条截图须加水印（见第五章），解说词同步录制或写入素材说明文档。

| 节点 | 截图内容 | 演示解说（录音/字幕要点） |
|------|----------|--------------------------|
| **N0 接入**（含 N1 去重） | 企微回调配置页 + 工作流 Start 节点入参（`msg_id`/`content`/`sender_id`） + N1 幂等去重日志（重复消息丢弃记录） | 消息从企微群进入工作流；重复消息被 N1 幂等去重静默丢弃，不计入任何统计分母 |
| **N8 知识问答** | LLM 节点 P2 知识问答输入（检索 context + 问句）与输出（P2 JSON 答复） | 直接可答类询盘由知识库检索 + 问答生成答复；无答案/低置信路径在 N9 校验后转人工 |
| **N14 人工确认卡片** | 企微审批卡片：报价草稿摘要 + 通过/修订/转人工按钮（WF-Main N14 推送） | 报价类询盘「AI 先做、人只审」：AI 起草报价并自校验（N13），人工只做三选一，AI 输出永不直达客户 |
| **N16 发出报价单** | 审批通过后 WF-Confirm 回调 → N16 发出报价单 + 企微发送回执 | 报价单仅在人工确认（或修订后确认）后发出；超时 4h 或转人工时绝不自动发出（B3 拍板口径） |
| **N22 发送答复** | N22 发送普通答复回执（自动答复路径 K→N22） | 自动答复类询盘的发送闭环；发送失败重试 1 次后转人工（N20） |
| **N23 埋点** | 状态落库代码节点输出（终态 + 埋点字段） + D9 看板对应行的数据来源对应 | 每条询盘终态（闭环/人工确认/异常转人工/归档）落库并埋点，看板数字可回算 |
| **N24 跟单提醒** | WF-Followup 定时触发日志 + 提醒推送截图（>2h 未跟进 / 报价发出 >48h 无回应 / 确认队列 >4h 升级主管 / 每日 09:00 汇总） | 跟单提醒为纯规则（P4，无 LLM），按节点规则驱动，提醒失败下个周期重投 |

> 补充：以上 7 组为作品集与演示必配；D6 接入配置页、D5 知识库上传页、D4 Schema 校验页可作附加素材（可选）。

## 五、Demo 定位水印/说明规范

### 5.1 统一文案（引用 D13 诚信口径）

| 形态 | 文案 |
|------|------|
| 主水印（录屏常驻） | `个人自演示 Demo · 客户画像虚构 · 非真实客户交付` |
| 短水印（截图/小图） | `个人自演示 Demo · 客户画像虚构` |
| 片头/片尾字幕（录屏） | 完整定位声明：`本案例为个人自演示 Demo，客户画像为虚构典型客户，用于演示外贸询盘数字员工的端到端交付链路，非真实客户项目交付。`（对齐 D13 3.2 作品集入口话术） |
| 成效数字出现时 | 画面角标追加：`成效为演示测算模型口径，以 D10 终稿为准` |

### 5.2 位置与字号建议

- **录屏主水印**：右上角常驻（避开操作区），1080p 下字号 20–24px，半透明白底黑字（对比度 ≥ 4.5:1），全程可见
- **截图短水印**：左上角或右下角，字号按图片宽度 2% 左右，不遮挡关键信息
- **片头片尾字幕**：底部居中，停留 ≥ 3s；片头在开场 10s 内出现
- **角标（成效数字）**：数字出现同屏时置于数字附近，字号与主水印一致

### 5.3 强制规则

- 每份素材（录屏/截图）**必须**含水印或随附说明文档；缺失即视为不合格素材，不得进入作品集
- 素材说明文档（M13）内逐条记录水印位置与核验结果
- 对外引用（作品集/简历/面试展示）一律使用已加水印版本，禁止以无水印母带对外展示
- **脱敏**：报价单/审批卡片截图须隐藏底价、成本、折扣上限等 L3 字段（D5 §7.2 密级），对外只展示金额、汇率等展示层字段；涉及报价数字统一用 D5 示例价格并标「示例数据」
